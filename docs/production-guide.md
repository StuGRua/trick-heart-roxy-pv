# 有限差分PV制作指南

适用于保留原PV时间线，用角色原画、姿态差分、跟踪和图层合成替换人物的制作。依据本项目返修经验整理；对连续大幅转身、复杂口型或大量新动作，应单独评估原画需求。

首次使用：复制[规划模板](../templates/pv-planning/README.md)，按下表推进。具体案例与代码见[v4返修记录](v4-revision.md#案例与证据)。

## 制作顺序

| 阶段 | 必须形成的产物 | 进入下一步前检查 |
| --- | --- | --- |
| 1. 锁定输入 | 原媒体哈希、实际帧率、总帧数、输出规格、需要保留的音轨/歌词、角色与造型约束 | 时间线来自真实媒体；常服、舞台服等有明确映射；是否戴手套等约束写入表格 |
| 2. 拆镜头与状态 | 镜头表、姿态事件表 | 除镜头首尾，还覆盖入场、消失、转头、眼嘴切换、接住/放开、遮挡变化；按源片记录，不能凭印象猜循环 |
| 3. 设计图层 | 图层表，每个物体的来源与遮挡关系 | 手、球、帽、杯、动物、框、字幕的唯一来源明确；相位变化时前后关系明确 |
| 4. 做难镜头样片 | 持物接触、移动框、循环动作、前景遮挡等代表片段 | 原速、半速和事件边界逐帧检查通过；未补齐的姿态先补图，不用局部拉伸凑过渡 |
| 5. 批量制作 | 采用原画、提示词、来源、裁切与注册信息、修改区间 | 每完成一类镜头就回归同类镜头；同一原画的所有消费者均覆盖 |
| 6. 全片检查 | 连续播放记录、重点抽帧、问题清单、修订前后对比 | 动作状态、接触、遮挡、人物身份与字幕可读性分别检查；记录实际看过的范围 |
| 7. 输出与交付 | 正片、所需字幕版、同步对比、媒体验证、素材/源码清单 | 基础帧和字幕缓存已同步；检查对象是最终MP4；标签和左右版本正确，音轨与帧数符合约定 |

难镜头先行是下一项目的流程建议；本片已验证其检查方法，但尚未量化它能节省多少工时或额度。

## 原画验收

姿态参考负责构图、头部尺度、头向、手腕位置与接触点；造型参考负责角色身份、发型、服装和配色。提示词写清各参考的职责。

- 先看占位、姿态和接触，再看服装细节。漂亮但位置不对的原画不直接进入跟踪。
- 睡眠、半睁眼、睁眼、左右转头分别记录；不能以相似表情代替实际状态。
- 每张采用原画记录来源帧、裁切框、提示词、文件哈希与消费者镜头。落选或仅作生成参考的图标明用途。
- 检查完整裁切边缘，避免把画框线、鸭子底座或纸边带进下一镜头。

## 接触与图层规则

| 镜头类型 | 处理原则 | 重点检查 |
| --- | --- | --- |
| 固定握杯、托帽 | 手与道具可联合补画，采用图承担接触关系 | 原片道具回贴不能再带回旧手或第二套轮廓 |
| 抛接球 | 球轨迹独立；原画保留对应握持姿势，明确前指/球/手掌顺序 | 接球、放球与源事件对应；前指只遮应遮部分 |
| 移动头像框 | 跟踪框几何，独立裁切内部及恢复外框 | 装饰碰框不能改变框尺寸；旧发完整覆盖，皮肤不被抠空 |
| 帘幕与家具 | 背景板、人物与前景分别处理 | 边缘、黑缝、开闭幕瞬间，以及清除区内的歌词与装饰 |

颜色只产生候选像素，还需结合实例、区域和边界。新旧角色的可见脸宽不能直接充当缩放比；先注册原画，再在源片同一角色的稳定特征之间估计运动，检查遮挡前后是否漂移。

## 检查与返修

- 所有帧范围统一使用整数帧和左闭右开区间`[start_frame,end_frame_exclusive)`；帧率从当前源媒体读取，不套用本片24fps。
- 正常速度检查节奏，慢放检查接触和跳动，状态边界逐帧检查。抽帧表记录样本范围，不写成“全帧人工看过”。
- 机器检查负责帧覆盖、输入/输出哈希、音轨、字幕保护及确定性；视觉记录负责姿态、身份、遮挡和连贯性。
- 改原画、跟踪或遮罩后，列出受影响镜头，重渲基础帧和字幕帧，再重新编码。未声明区间保持原样。
- 每轮重要修订保留前后同步对比。实际解码抽帧核对左右来源，避免版本标签正确但视频接错。
- 记录每轮补图次数、采用次数、返工原因和可取得的阶段用量；缺少数据的部分保留未知。

## 复用边界

可直接复用：抽帧、按帧合成接口、片段输出、审阅播放器、同步对比、音轨和字幕验证方法。

每片重新核对：角色造型、原画、姿态/表情事件、具体颜色阈值、裁切坐标、跟踪锚点、图层顺序和原作保留范围。

本指南和模板是复用入口，当前渲染器仍采用本片专用镜头定义。等下一支PV验证后，再把稳定部分抽成公共接口或薄skill。

对外简介保持简短：作品、实际改进、方法、已知成本与致谢。内部版本映射、检查记录和未执行事项保留在工程记录中。
