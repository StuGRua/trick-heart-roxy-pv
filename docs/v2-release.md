# v2：这次改了什么，以及踩过的坑

对外发布版本为 **v2 / v2.0.0**，对应工程内部的 **v4**。首版 v1.0.0 对应内部 v3。内部文件名保留，避免打断帧号、素材和验证记录的对应关系。

## 这次的改进

这轮从观众指出的四处问题开始，重新检查全片后归并为12组返修。主要变化：

- **手与道具**：修开头持牌时牌边截指、持帽时旧白手套回贴、握杯时双轮廓。入场还没有手的几帧不再误贴肤色碎片。
- **头像与画框**：补全约00:14右下框的覆盖，清除露出的红发；修蝴蝶靠近画框时头像跳动/出框，以及嘴唇、颈部被误抠除的孔洞。
- **动作与表情**：补约01:22的站立差分；杂耍改为13张姿态原画，由源片手形和表情决定切换，球与前指分别合成。补闭嘴、张口笑、旋涡眼、单眼睁开和眨眼，醒来段加入正面、转右、转左三个状态。
- **遮挡与服装**：修开帘矩形和旧人物碎线、闭幕缝隙漏人、鸭子重复及竖框白边；重画兔子膝部和片尾的常服细节，恢复误遮住的原歌词和背景蝴蝶。
- **复查入口**：正片、中文字幕版、原PV同步对比均更新；审阅页增加12个问题编号、精确帧号跳转，保留拖动、逐帧、慢放和片段循环。

原曲、157秒时间线、双造型、译文、字体与两处英文视觉署名保持原有安排。首版文件和构建入口保留。

## 制作中踩过的坑

| 坑 | 本片里的表现 | 这轮的处理与后续做法 |
| --- | --- | --- |
| 单帧正确，不代表动作完整 | 代表帧看着没问题，连起来才发现接球、半睁眼和醒来转头丢了 | 先列完整状态链，检查入场、过渡、接触、放开和消失；补原画后看连续帧和原速/半速片段。 |
| 颜色不是物体身份 | 金色可能是蝴蝶、字、衣料或框；黑线可能是帘幕，也可能是旧人物 | 颜色只筛候选，再结合区域、边缘连通关系、具体物体和事件范围决定图层。 |
| 道具保留两套，手也会多一套 | 新原画已有杯子和手，又恢复源杯，把旧手线带了回来；鸭子也出现双底座 | 每个手、帽、杯、鸭子明确唯一来源。需要接触的姿态联合补画，再拆清前后遮挡。 |
| 整体移动代替不了局部动作 | 同一张图平移缩放，人物仍像纸片；杂耍手势跟不上球 | 补关键手势和表情。不能只凭注释猜固定循环，要从源片实际事件选择差分。 |
| 脸宽变化不一定是镜头缩放 | 球遮脸改变可见肤色宽度；新旧角色脸型不同，也会把手拉离球 | 原画先按源裁切注册；在源片同一角色之间估计运动，再用头发和衣服的稳定特征校正。 |
| 清掉旧人物，也可能清掉背景 | 沙发段的蝴蝶和日文字被一起盖住；大块区域清理留下矩形 | 独立准备背景与前景，检查新人物外的像素和遮挡顺序；字形从干净原片素材注册恢复。 |
| 检查了新PNG，却交付旧MP4 | 局部修改后只更新预览，字幕缓存或编码文件没有同步 | 更新全部受影响基础帧和字幕帧，连续检查后统一编码，最终验证针对实际成片。 |

这套方法能完成有限差分组成的PV，但仍有大量镜头规则和返工。换成AE能让图层和关键帧更容易人工编辑，缺失的转头、手势与表情原画仍然需要补齐。这里记录的是这支片子的经验，不把专用规则当成通用动画能力。

## 验证与成本口径

本轮采用24张新原画，其中13张用于杂耍。两版各3768帧：1297帧有修订，2471帧与首版内部v3的PNG文件哈希相同；变化仅限声明区间。100处角色/区间边界重渲、100处字幕边界重渲、字幕alpha外像素保护、三份成片严格解码及原AAC/PCM一致性均通过。16项回归测试通过。结果见[验证基线](../tests/v4-verification.json)和[验证范围](validation.md)。

视觉检查使用全片审计、重点连续采样260张、字幕样图20张及实际播放器复核，不声称人工逐一看过全部3768帧，也不声称没有任何瑕疵。

用户记录的 **GPT 20x的50%周额度** 是首版制作成本；本轮返修没有单独统计，不能把它当成含v2返修的总成本，也不换算成现金或工时。

## 复现与下载

[v2.0.0 Release](https://github.com/StuGRua/trick-heart-roxy-pv/releases/tag/v2.0.0)提供源码包、非MIT资源包和SHA256校验文件。解包及原作输入准备见[README](../README.md)，构建命令为：

```bash
.venv/bin/python tools/build.py --version v4
```

输出文件继续使用`roxy-full-v4.mp4`、`roxy-full-v4-zh.mp4`、`roxy-full-comparison-v4.mp4`。完整原画提示词与来源在[素材记录](../assets/revision4-manifest.json)，实现契约见[内部v4修订说明](v4-revision.md)。

感谢[无糖淀粉的千早爱音版](https://www.bilibili.com/video/BV1giez6QEzc)分享人物差分原画与程序合成的方法。原曲/原PV：[MIMI《トリックハート》feat. 重音テトSV](https://www.bilibili.com/video/BV1ohuu6LEBP)。本版视觉二创：StuG_III + GPT6Astra。
