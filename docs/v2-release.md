# v2改进与踩坑记录

## 改了什么

- 修持牌穿模、画框漏红发、嘴唇和颈部误抠、持帽白手套残留、握杯重影。
- 补站立动作、13张杂耍姿态、缺失表情和醒来转头。
- 修帘幕残影、鸭子重复、人物出框，重画兔子膝部与片尾常服特写。
- 更新正片、中文字幕和同步对比，增加问题定位与逐帧检查入口。

## 踩过的坑

1. **只看静帧会漏动作。** 接球、眨眼和转头必须连着看；先列关键姿态，再补原画。
2. **同色不代表同一物体。** 蝴蝶、衣服、字和画框可能都是金色，遮罩要结合位置、边界和前后关系。
3. **道具只能有一套来源。** 新图已有杯子或鸭子，再盖回原片道具，就会出现重影和旧手指。
4. **平移缩放补不出手势。** 杂耍要按实际接抛球动作切换差分，不能拿固定周期硬套。
5. **脸宽不是可靠的缩放尺。** 球遮脸会改变可见肤色面积；新旧角色脸型也不同。用源片中稳定的头发、衣服特征跟踪。
6. **清旧人物时别把背景一起擦掉。** 原歌词和蝴蝶也曾被盖住，背景、人物和前景应分层处理。
7. **最后检查实际成片。** 原画改完，要同步更新合成帧、字幕和编码文件，不能只看新预览。
