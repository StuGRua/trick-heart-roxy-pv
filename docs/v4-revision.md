# v4 视觉返修

v4是工程内部修订号，对外发布为v2.0.0；保留可重建v3的入口，公开v1.0.0对应v3。版本映射、改进与坑点见[v2更新说明](v2-release.md)。

## 范围与入口

返修持牌接触、头像框漏盖和出框、肤色误抠、站立差分、杂耍相位、持帽白手套、杯手重复轮廓、帘幕残影、衣料特写、鸭子重复，以及表情/醒来状态遗漏。角色和原画仍由图像模型绘制，程序只安排事件、跟踪、遮罩和图层。

完整构建：`.venv/bin/python tools/build.py --version v4`。已有源帧与 v3 帧时可依次运行：

    .venv/bin/python tools/revision4_composite.py --all
    .venv/bin/python tools/revision_encode.py --version v4
    .venv/bin/python tools/chinese_subtitles.py --version v4 --render --encode
    .venv/bin/python tools/revision4_verify.py --sheets
    .venv/bin/python tools/revision4_verify.py

单帧样张：`tools/revision4_composite.py --frames 48 350 1260 2024 3083 3320 3376`。更新已有完整帧缓存：`--update 2472:2785`，区间左闭右开。改变原画或算法后必须重跑所有受影响区间，再重新编码和验证。

## 图层与事件契约

- v4 未声明修改的帧必须与 `tests/frame-baseline.json` 中 v3 PNG 的 SHA256 相同；旧 MP4 如仍在本地，必须匹配 `tests/v4-revision-contract.json`。
- 纸色头像框先分离金色外部装饰，再取几何边界；该方法不用于本身是金色的对话框。后者保留 v3 路径。框内皮肤阴影不因颜色接近背景而被抠除。
- 持帽和纸杯使用联合原画里的裸手/道具，禁止又盖回另一套旧手或道具。鸭子采用单一原画图层，避免两套鸭子叠加。
- 帘幕只恢复连接画面外缘的深红区域并填补其内部线条；黑色人物轮廓不参与实例识别。
- 杂耍十三张原画以源帧的手形和表情选择，不用固定周期猜相位。原画已按源裁切注册，不再用不同角色的肤色脸宽比来缩放。球逐帧来自源位置，握持时仅前指遮住球，不用整个手掌挡住球心。
- 小幅站立差分有两张原画，选择依据源姿态；嘴/眼的关键事件用整数帧记录在 `tests/v4-revision-contract.json`。
- 沙发醒来分为正面、向右、向左三种原画，按源姿态切换。恢复被新靴子覆盖的原日文时，使用同曲干净字形注册；不可把颜色相近的旧靴筒一并恢复。
- 竖向头像框只裁入头脸，不能带入原画上方鸭子的白色下沿。半睁眼与闭眼是不同状态，不能用同一张睡眠原画替代。
- 中文字幕只有一个译文、事件、字体与样式来源；`--version` 仅切换底片和输出。子进程显式初始化版本，避免把 v4 字幕烧到 v3 上。
- 图像生成记录在 `assets/revision4-manifest.json`，采用 PNG 的 SHA256 与资源包清单同步。原PV裁切参考可以从源帧号和裁切框重新提取，不随代码发布。

## 验证与错误处理

| 条件 | 处理 |
| --- | --- |
| 纸框未找到 | 报出具体帧号并停止，不把原人物当作回退结果 |
| 杂耍闭幕前脸锚点丢失 | 报错；闭幕后只允许沿用最后可见源锚点 |
| 未声明区间发生像素变化 | 完整验证失败 |
| 字幕 alpha 外发生变化、边界重渲不一致 | 完整验证失败 |
| 帧数/帧率/时长、AAC或PCM不匹配 | 完整验证失败 |
| 图片或姿態在单帧正确 | 仍需源片/v3/v4连续对照，不能直接视为动作验收通过 |

好例子：新旧人物使用各自正确的裸手原画，源球按事件穿过前指/后指层；基础例子：已确认静态镜头复用一张原画并整体跟踪。错误例子：用全屏“黄色”恢复道具、用整张手掌遮住球，或把机器重建一致误当成视觉正确。

回归命令：`.venv/bin/python -m unittest discover -s tools -p 'test_*.py' -v`。重点断言：蝴蝶碰框不改变框尺度、内部肤色不被当背景、未改帧复用 v3、切换字幕版本不改变 cue。实际全片和连续帧证据位于本地 `review/`；这些记录不自动替代用户的美术审阅。

## 本次遗漏与预防

此前按几个代表帧检查，没有覆盖入场、手势转换、半睁眼、接球和醒来转头等中间状态。静态原画看起来正确，并不能说明连续事件完整。本次把动作状态与接触关系作为检查单位，保留源帧号、采用原画、遮挡面积和球心记录；新原画先与源动作接触位置对照，再合成完整片段。

颜色阈值只用于产生候选像素，还要加实例边界与图层来源约束。金色可能同时是蝴蝶、文字、衣服或框；黑线也可能同时属于帘幕和人物。将这些候选直接恢复到画面，会重新引入旧人物或遮掉新人物。

角色间可见肤色宽度不等于镜头缩放。新原画按源裁切注册后，只在源片同一角色之间估计运动；遮挡导致的脸宽变化再用头发、衣服特征校正。每次更新原画后，重渲全部受影响帧和字幕缓存，视觉检查完成后再统一编码，最后验证实际输出文件，防止检查的是新PNG、交付的却是旧MP4。
