# 验证范围

tests/v3-verification.json与tests/subtitle-verification.json是迁移前已经交付的当前版本基线。tests/frame-baseline.json保存两套3768张PNG的文件哈希，用于本机依赖/字体一致条件下的完整重建检查。

源PV、AAC、字体和译文输入哈希分别在research/source-baseline.json与subtitles/input-baseline.json。迁移后的帧必须与交付基线一致后，才允许删除旧缓存。仅存在一个MP4或仅FFmpeg退出成功，都不能作为完成证明。

正式验证分别检查：

- 输入与旧成片的哈希；整段覆盖0–3767，24fps；视频157秒，音频157.013333秒。
- AAC压缩内容与解码PCM均与原音轨一致；成片严格完整解码。
- 角色/字幕乱序重渲确定性；字幕alpha外没有像素改变，无字幕帧与v3完全一致。
- 只有中途与片尾两处英文视觉署名；中文字幕不覆盖它们。
- 审阅HTTP Range协议、拖动、版本切换、逐帧和连续播放。
- 公开文件白名单、敏感路径、导入依赖、许可证边界和打包CRC。

视觉审阅是独立环节。此前已逐页查看全片与返工联系表、字幕60帧样张并进行原速和半速播放。机器检查不会替用户批准美术效果。当前采用有限原画差分，不声称每帧都是新的绘画；部分旧人物遮挡下的局部道具会按显式规则补全。

## 独立仓库迁移验证

2026-09-29在新的独立Python虚拟环境中，从锁定依赖、源媒体和采用原画重新构建全部输出，没有使用旧合成帧缓存。v3和v3-zh各3768张PNG、合计7536张，与已交付帧的SHA256全部一致；v3、同步对比、v3-zh三份MP4的SHA256也全部一致。

公开白名单与脱敏检查通过，4项发布白名单测试和6项Range服务测试通过。详细本地证据保存在review/migration-verification.json与review/migration-build.log，发布包只包含必要源码与基线，不包含本机过程日志。

## v4本地返修验证

2026-09-29完成12组视觉返修，采用24张新原画，其中杂耍13张；26条图像生成记录包含两张仅用于后续生成参考的版本。源帧、v3与v4联系表、260张重点连续采样及20张字幕样图用于视觉检查；原始全片审计覆盖78个合成区间。另保留开头、杂耍、后段三段源片/v4同步视频。此覆盖不代表人工逐一看过全部3768帧，也不替代用户的最终美术审阅。

最终本地机器检查：两版均3768帧；1297帧有修订，2471帧与v3逐文件SHA256一致，变化仅限声明区间。100个角色/区间边界乱序重渲与100个字幕边界重渲一致；字幕alpha外改变0像素，704个无字幕帧与v4底片完全相同。三份MP4保持24fps、157秒视频，AAC和解码PCM与原音轨一致，严格完整解码通过；旧v3三份MP4哈希保持原样。

16项回归测试通过，包含6项图层/版本测试、6项HTTP Range测试和4项公开白名单测试。55个公开文件通过语法、JSON、私人路径与Git候选集合检查；依赖、输入哈希和字体预检通过。可复核的本地完整报告为review/v4-verification.json。对外v2.0.0采用独立v2源码包和非MIT资源包，内部成片与帧缓存仍使用v4文件名；v1.0.0仍为v3。公开验证基线另存tests/v4-verification.json。
